# Night Scent Import

Catálogo web estático de Night Scent Import.

## Publicar con GitHub Pages

1. Crear un repositorio nuevo en GitHub.
2. Subir `index.html` y `.nojekyll` desde esta carpeta.
3. Ir a **Settings → Pages**.
4. En **Build and deployment**, elegir **Deploy from a branch**.
5. Seleccionar la rama principal (`main`) y la carpeta `/ (root)`.
6. Guardar y esperar a que GitHub Pages publique el sitio.

El catálogo está preparado como archivo HTML autocontenido: las imágenes están embebidas dentro de `index.html`, por lo que no hace falta subir una carpeta `assets`.


Actualizado: la barra de marcas funciona horizontalmente en celular y tiene una flecha para minimizar/mostrar las marcas.
